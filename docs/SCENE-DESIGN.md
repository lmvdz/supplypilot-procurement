# Original spatial journey

The public overview uses an original procedural WebGL renderer: signed-distance fields, surface normals, soft shadows, studio reflection approximations and fog. It imports no reference-site assets or code. All artwork is computed locally; the scene does not make network requests. Licensed Manrope fonts are served locally (license: site/Manrope-LICENSE.txt).

The sculpture, palette and narrative differ by project. Scroll follows a continuous camera path; the final scene returns to the opening pose. Only deliberate wheel/touch scrolling wraps, and focused closing links, keyboard reading, paused motion and reduced motion keep a normal end. Context loss or unavailable WebGL preserves a static illustration and all content. The canvas is decorative; the complete experience remains native text, links and controls.

The build embeds all public assets into the Worker. Visual acceptance requires independent rendered desktop/mobile and motion review; implementation tests alone do not establish design quality.
